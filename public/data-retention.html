Local data and retention

This page describes the current local-first website release. It does not describe a future cloud account service.

Where data is stored

Learner profiles, preferences, lesson progress, quiz attempts, bookmarks, family goals, teacher plans and optional timed sessions are stored in the browser’s local storage.

How long it remains

Most local progress remains until the user clears it, the browser removes site data or the device/browser profile is replaced. Optional timed-session records are limited by the application to recent records and are not intended as permanent attendance evidence.

Export

Use Settings and Data to download a JSON backup before changing devices, browsers or browser profiles.

Deletion

Use the confirmed reset action in Settings to remove KirthiVerse local records. Browser settings can also remove site data. Deletion from this browser cannot remove copies that a user previously exported.

Cloud accounts

The current release does not create a remote learner account or synchronise scores to a KirthiVerse database. Future authenticated services require separate notices, consent, retention controls and deletion workflows before launch.
