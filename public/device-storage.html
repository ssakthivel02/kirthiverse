Local-first release

How this website stores learning information.

KirthiVerse currently uses browser storage to remember learner progress on the device being used. It does not use behavioural-advertising cookies or third-party analytics SDKs.

Information stored locally

  • nickname, avatar, grade band and learning preferences;
  • lesson completion, bookmarks, quiz attempts, XP and streak information;
  • family goals, optional timed sessions and teacher planning notes;
  • mistake-review records and local learning notes.

Technologies used

The interactive website uses localStorage for the learner record and browser Cache Storage through a service worker for selected application files. The service worker enables offline recovery and controlled application updates.

What this means

  • Another browser or device will not automatically see the same scores.
  • Clearing browser data can remove the learner record.
  • Private/incognito windows may delete records when closed.
  • Use Settings and Data to export before changing devices or clearing data.

Control

You can export, import or reset the complete local record. You can also clear browser storage using the browser’s own privacy controls. Read the retention explanation and privacy notice.
