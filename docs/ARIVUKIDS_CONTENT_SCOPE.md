# ArivuKids Legacy Content Scope

ArivuKids is the legacy identity for the existing KirthiVerse web experience. The migration should preserve the current learning platform while separating it cleanly from future KirthiVerse flagship development.

## Preserve
- Learning Worlds and subject navigation
- Maths, Science, English, Tamil, Coding, Geography, Art and Music content
- Guided tutor flows
- Parent-facing progress visibility
- Local-first privacy posture
- PWA/offline and repair/reset behaviour
- Accessibility and legal/safety pages

## Controls
- Do not change mobile package IDs in this web-only migration.
- Do not expose child data or introduce cloud profile sync without a separate approved architecture.
- Keep internal KVS route/release IDs unless a tested functional change requires otherwise.
- Preserve direct-route recovery and service-worker safety.
