# KVS-PLATFORM-001 Quality Wave 12 — Hidden trust-resource deployment hotfix

## Status

Implemented on `hotfix/kvs-security-contact-deployment` after the production build and GitHub Pages deployment succeeded but live verification detected one missing resource.

## Evidence-derived root cause

The production artifact generated by the build contained `.well-known/security.txt`, but the GitHub Pages upload omitted hidden paths. As a result, all application, content, privacy, PWA, direct-route and deployment-metadata checks passed while `/.well-known/security.txt` returned HTTP 404.

This was an artifact-packaging defect. DNS, Cloudflare Workers, the custom domain and certificates were not implicated and were not changed.
